# 只保留关键回归

默认 `npm test` 由 `test/essential-suite.json` 明确列出核心套件，不再自动把每项功能的新测试加入所有 PR。已实际删除 63 个历史、重复或细粒度套件；没有改名藏成另一套默认全量测试。

保留的边界集中在：材料导入/持久化/恢复、本地资料保护、真实问答编排和项目切换、长问题及最终请求预算、Qwen/DeepSeek 协议与流式结束、超时/取消、证据和报告脱敏、窗口基本捕获保护、安装包基本配置。新增核心测试应验证这些完整流程或真实故障，不为每个按钮、内部函数和措辞单独建测试。

本轮多轮与v2升级后的清单为24个套件，183项关键断言：增加了真实发言修订/取消隔离、30轮回指、v1迁移及导入崩溃补偿、所选JD到实际请求、双裁判证据与加密评测边界。未恢复先前删除的细粒度套件。数量随真实缺陷回归调整，以运行输出为准。

删掉的覆盖包括各快捷键和尺寸组合、逐字界面文案、每种语音分段/音频格式/模型下载的细节、历史检索/缓存/低延迟实现的重复单测和大量纯静态断言。生产功能保留；今后只有修改到对应能力且存在具体风险时，才做针对性验证。

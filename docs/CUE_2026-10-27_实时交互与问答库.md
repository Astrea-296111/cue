# 2026-10-27 实时交互、问答库与屏幕任务

本轮从 `358a728fa21ec5ac5537afd78554ad8e5030631a` 开始，正好等于用户任务书的审阅基线。本次不复用 10 月 26 日模型成绩作为新功能的通过证据。

## 语音还没结束时

按 **Ctrl+Enter**。已有可回答的临时转写时立即发出请求，不等 final。只有“如果”“你们的权限”等半句时，界面显示“已记住按键，正在补全当前问题”；同题首次可回答转写到达后提交一次。默认等待上限 5 秒；超时会提示仍缺题意，保留转写供再次提交。未开启监听且没有内容时，会提示开启监听或输入问题。

“嗯”“这个我了解了”“好，OK，对，OK”，以及实质回答，都不会删除手动答题目标。题目提交后仍保留；同题同版本重复按键不再计费。需要再答一次用 **重答**；面试官补充了条件，按 Ctrl+Enter 会取消旧流并使用新版本。旧答案卡上保存当时绑定的问题，避免把旧题答案当成新题答案。

双声道模式将用户选定的系统音频保留为面试官目标，麦克风重复片段标注回声疑点。单麦克风模式可在设置切换，并在对话记录中手动选定说话人。原文、来源和人工修订均保留。Qwen 音频时间使用 provider 相对时间加首个 PCM 软件时间锚，**不是硬件同步声纹判断**；不能承诺消除全部串音。

## 最近轮次与本人语音

在 **设置 → 风格 → 实时上下文** 选择最近 1、2、3 轮，内部对应当前题加前 0、1、2 轮。默认最近 3 轮，但独立问题实际读取零轮历史。轮次按面试官题目计算，同一题多段转写或多次重答只算一轮；没有请求 CUE 的新问题也占轮次。

默认关闭“参考我实际回答”。关闭时本人语音不进入模型正文、检索、项目推断或纠错上下文；录音复盘和简历资料仍保留。显式开启后，也只取配置窗口内的发言。实时答题不读取旧 AI 答案、归档记忆或旧项目进度。手动锁定项目仍是显式资料范围；当前明确点名另一项目时以当前问题为准。

## 两个截图快捷键

**Ctrl+H** 和 **Ctrl+?**（标准键盘为 Ctrl+Shift+/，另有 Ctrl+Shift+Enter）均先识别本张截图的具体任务。算法、单条 SQL、调试、系统设计、Vibe Coding 和未知任务共用一个路由器。IDE 或聊天侧栏本身不决定模式。

- 普通解题保留思路、复杂度与代码能力。
- Vibe Coding 输出题目边界、候选人的设计、可复制给 AI 的提示词、3–6 步验收与纠错提示。普通口述的 260 字限制不适用于它。
- 当前步骤靠前，后续步骤可折叠；“复制当前提示词”只复制提示词正文，不自动发送到外部 AI。
- 默认一次模型调用完成视觉任务提取与路由。Vibe 的五步指导由当前任务数据驱动的本地协议编译，确保每步四项与运行时边界；模型额外正文不直接展示，诊断保留原文并注明展示来源。其他解题正文仍来自同次模型调用；路由头未确认前不显示代码。不支持视觉的模型先提示更换视觉模型或输入题目，不发送图片假装识别成功。
- 顶部“屏幕模式”可覆盖为自动、普通解题、Vibe Coding。覆盖只作用当前任务。

新截图默认新题。要在同题修错，先点击“下次截图继续本题”。可粘贴本题 DDL/题面，点击“保存为当前题附件”；全文留在当前任务，较长附件按当前需求取有标记的摘录，不受口述轮次窗口删除。每题最多三个 64KiB 文本附件。只有当前截图观察和用户明确确认的验收项进入任务状态，AI 自述不会标记为已验收。点击“结束本题”立即清空附件、阶段、错误、确认项和覆盖模式。

## 导入项目问答

在 **设置 → 项目资料 → 项目问答库** 点击“导入 JSON…”，或使用编辑器预览标准文件。先预览新增/更新、字符数和冲突，再应用。自己的文件只保存在本机材料工作区。

模板与格式：

- [JSON 模板](examples/cue-qa.template.json)、[JSON Schema](examples/cue-qa.schema.json)
- [严格 Markdown 模板](examples/cue-qa.template.md)
- [详细格式和 facts v2 兼容说明](cue-qa-format.md)

模板是未启用的设计示例。编辑答案、项目与边界后将 `enabled` 设为 `true`。不需要填写 commit、hash 或内部路径。

匹配命中时显示“问答库命中”和标准问题、项目、版本；直接返回原文，包括影响结论的边界，**不需要 API Key、没有模型调用**。长原文完整保留，不用口述截断器裁剪。在问答库里可试问、编辑、启停、删除、导出，并切换短答/详答；切换后对已有题目点击“重答”查看对应版本。

部分匹配交由原有模型链路整合资料，实际使用了问答资料时显示“基于问答资料生成”。项目不明确、版本冲突、相反否定、数字/单位条件不同或多问覆盖不足时不直达。同义表达主要依赖用户 aliases、有限规范化和保守字符特征，不能把相似度当作概率，也不保证任意自由改写都能命中。

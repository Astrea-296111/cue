# 材料检索调整与清理审计

本次保留所有用户资料和原始文件。没有删除 QuestionResolver、语音、资料迁移、旧索引兼容、评测或语义模型依赖；未将文件删除数量作为性能指标。

- `src/latest-question.js`、渲染器中的旧转写辅助函数及 Whisper 准备脚本：暂保留；尚未完成全部动态调用、打包和迁移核验。
- `src/project-material-service.js`、`src/project-registry.js`：新导入的源码快照按项目记录活动来源，同项目旧来源仍存在材料快照中；旧指针没有活动来源时沿用旧行为。重复导入相同版本可不发布新 generation；回滚恢复上一代。旧版来源目前仍会存储和参与索引构建，尚不能宣称 RSS 或索引构建成本降低。
- `src/project-evidence-policy.js`：相同项目、角色、来源性质、状态、版本和正文的事实候选去重；保护证据设置有限上界，最终窗口预算仍执行。不同来源性质或版本不会因为正文相同而合并。
- `src/qa-import.js`、`src/qa-index.js`：项目问答默认作为生成资料，已有项目直答偏好保留在文件但不会绕过模型；显式指定为通用知识并选择原文直答的条目仍支持原有行为。
- 已验证失败和不足：源码与问答的自然语言冲突尚未形成可核验的结构化 claims／冲突裁决；缺少按需展开详答、完整证据账本和旧快照切换界面。语义重复判定和需要人工确认的冲突不会被自动删除。

素材导入先预览、确认，再以材料 generation 原子发布。设置页显示活动来源的内容指纹前 12 位和归档数量；旧版可通过现有上一代回滚恢复。首次升级已有双来源数据时，重新导入需要激活的 ZIP 才会选择活动来源，升级本身不会自动删除或修改用户资料。

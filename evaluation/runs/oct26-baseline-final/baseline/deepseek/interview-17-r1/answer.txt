三者定位不同：Function Call 是模型输出结构化调用意图、由宿主执行并回填结果的机制；MCP 是跨工具、跨客户端的开放协议，解决工具接入和发现的标准问题；Skill 更像可复用的任务说明或操作流程包，把某类任务的步骤、约束和配套资源封装起来，由 Agent 按需加载使用。

我会这样区分取舍：Function Call 关注“这一次调用怎么发起和执行”，MCP 关注“工具怎么被统一暴露和复用”，Skill 关注“这类任务该按什么流程做”。比如一个查库任务，模型通过 Function Call 触发查询，查询工具由 MCP Server 统一提供，而“先校验参数、再查库、失败重试”这一套步骤写进 Skill。验证时我会分别看调用参数和结果回填、MCP 工具描述与权限边界、Skill 加载后流程是否稳定可复用。

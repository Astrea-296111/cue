Claude Code 的关键在于把 Agent Loop 做成一个受控的工具调用循环，核心是模型、工具、权限和上下文四层。我会这样设计：单次循环先让模型根据当前上下文生成下一步动作，也就是要调用哪个工具、传什么参数，然后交由工具调度层执行；执行结果再回填上下文，进入下一轮，直到模型判断任务完成，或者触发停止条件。工具层至少要有文件读写、Shell 命令和搜索三类基本能力，每类都定义清晰的输入结构、返回格式和超时；权限层在工具真正执行前做拦截，比如写文件或跑命令需要用户确认，或者在安全模式下限定白名单；上下文层负责压缩和历史裁剪，避免长任务把窗口撑爆。取舍上，我会优先保证每一步都可中断、可观测，也就是每轮工具调用都有日志和可回放记录，而不是一开始就追求复杂编排；验证的话，先用一个“读文件—改一行—跑测试”的小任务端到端跑通，再逐层加入权限和上下文压缩，比如让 Agent 修改一个配置文件后执行对应测试，观察每一步的输入输出是否符合预期。

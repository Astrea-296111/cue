核心做法是把全量工具 Schema 改为“目录索引 + 按需加载”。

1. **初始只注入轻量目录**：50 个外部 MCP 工具不再把完整的参数定义和描述塞进 System Prompt，而是只保留服务名、工具名和一句话摘要。这样初始上下文从 18.6k 降到了 4.2k。
2. **搜索与动态加载**：当模型需要调用某个工具时，先通过 ToolSearch 匹配相关能力，找到目标后再单独拉取该工具的完整 JSON Schema 和参数定义注入当前轮次。
3. **执行校验**：拿到完整 Schema 后，用 Pydantic 做参数校验，确保调用合法。

这个优化主要降低的是**首轮初始 Token**，因为避免了无关工具的干扰；但要注意，如果任务复杂、涉及多个工具切换，全程总 Token 未必同比例下降，因为后续轮次会有额外的发现和加载开销。

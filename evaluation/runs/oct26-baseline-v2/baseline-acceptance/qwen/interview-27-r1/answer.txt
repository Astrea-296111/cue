我会设计一套分层评估体系来量化这个 Coding Agent 的任务完成度。首先，针对文件修改和命令执行这类核心能力，我会构建基于 Git Diff 的自动化测试集，通过运行单元测试或集成测试来验证代码变更的正确性，这是最直接的“通过/失败”指标。其次，对于多轮对话中的上下文保持和工具调用准确率，我会引入类似 SWE-bench 的基准思路，记录模型在解决特定 Bug 或实现功能时的步骤数、Token 消耗以及最终是否通过所有断言。

为了更细致地分析瓶颈，我还会建立过程性评分机制，比如统计 MCP 工具调用的成功率、无效重试次数以及检索结果的命中率。这样不仅能看最终结果，还能定位是检索不准、规划错误还是执行失败，从而针对性地优化 Prompt 或工作流编排。

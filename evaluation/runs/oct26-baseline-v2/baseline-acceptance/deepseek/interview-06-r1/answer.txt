我了解过，分别是 Transformer、注意力机制和上下文窗口。简单说：

1. **Transformer** 是大语言模型的基础网络结构，核心是用多层堆叠的自注意力和前馈网络处理序列。它不像 RNN 那样逐步递归，训练时能和 GPU 并行计算；每一层都会在 token 之间交换信息，层数越深，能组合的语义关系就越复杂。

2. **注意力机制** 简单理解就是每个 token 根据相关性，给其他 token 分配不同权重再聚合信息。我一般用 Q、K、V 解释：Q 是当前 token 想找什么，K 是其他 token 能提供什么，两者点积算出相关性，再对 V 加权求和。它的好处是能直接建模长距离依赖，比如指代和语法搭配；代价是计算量随序列长度平方增长。

3. **上下文窗口** 就是模型一次能看的 token 数量上限。窗口太大会让注意力成本和显存压力明显上升，所以一般按任务截断、分块或压缩；不是窗口越大，效果就机械地越好。
